# Zapret VN для Linux

Обход DPI-блокировок во Вьетнаме (Steam, Roblox, Telegram, торренты и др.) **без VPN**.
Это Linux-порт [Zapret VN](https://github.com/MrMe0ws/zapret-vietnam): те же стратегии обхода и те же списки доменов, но вместо Windows-программы — скрипт вокруг официального `nfqws` из [zapret](https://github.com/bol-van/zapret) v72.13.

> Неофициальный порт. Автор Windows-версии (Meows) к нему отношения не имеет. Лицензия: MIT (см. `LICENSE.zapret-vn`, `LICENSE.zapret`).

## Что нужно

- Linux с ядром, где есть NFQUEUE (`nfnetlink_queue` — есть в любом обычном дистрибутиве), **root/sudo**
- `nftables` **или** `iptables` (nftables предпочтительнее), `curl`, `bash`
- Архитектура x86_64 или arm64 (оба `nfqws` уже в пакете). Для других — `nfqws` из релиза zapret и `ZVN_NFQWS=/путь/к/nfqws`

## Установка одной командой

```bash
tar xzf zapret-vn-linux-1.0.0.tar.gz
cd zapret-vn-linux-1.0.0
sudo ./zapret-vn.sh install
```

`install` делает всё сам:

1. копирует программу в `/opt/zapret-vn` и создаёт команду `zapret-vn`;
2. проверяет хеши `nfqws` и fake-файлов;
3. ставит и запускает службу systemd — **она включена в автозапуск и стартует вместе с системой**;
4. включает защищённый DNS (DNS-over-TLS). Если после этого имена перестают разрешаться (порт 853 закрыт сетью), изменение откатывается автоматически;
5. проверяет, открываются ли Steam / Roblox / Telegram.

Параметры: `--no-dns` — не трогать DNS; `--pick` — сразу подобрать стратегию автоматически (1–3 минуты).
Если часть сайтов в проверке ✖ (другой провайдер, не FPT): `sudo zapret-vn pick`.

> **Почему именно `install`, а не запуск из распакованной папки?** `nfqws` после старта сбрасывает права до пользователя `nobody` и только потом читает списки. Если папка лежит в `/root` или в домашнем каталоге с правами 0700/0750 (Ubuntu), он не стартует. Скрипт проверит это и подскажет решение. Запуск от root вместо этого: `ZVN_USER=root` — работает, но менее безопасно.

## Команды

| Команда | Что делает |
|---|---|
| `start` / `stop` / `restart` / `status` | управление обходом |
| `check` | проверка Steam / Roblox / Telegram / Discord (+ найденные автоматически) напрямую, мимо DNS провайдера |
| `pick` | автоподбор: перебирает все 10 стратегий, выбирает лучшую (1–3 минуты, обход на это время выключается) |
| `strategy [id]` | список стратегий / выбрать стратегию |
| `dns-on` / `dns-off` | защищённый DNS (DNS-over-TLS на 8.8.8.8 / 1.1.1.1) через systemd-resolved |
| `install [--no-dns] [--pick]` | всё в одном: `/opt/zapret-vn` + служба (автозапуск) + защищённый DNS + проверка |
| `install-service` / `uninstall-service` | только служба / удалить службу и правила файрвола |
| `verify` | проверить хеши `nfqws` и fake-файлов |
| `rules` / `args` | показать правила файрвола / командную строку `nfqws` (для проверки) |

## Списки доменов

В папке `lists/` (после `install` — `/opt/zapret-vn/lists/`):

- `vietnam.txt` — сайты, к которым всегда применяется обход (поддомены включаются сами)
- `exclude.txt` — исключения (банки и т. п.)
- `autohostlist.txt` — сюда `nfqws` сам добавляет сайты, которые 3 раза подряд оборвали соединение

После правки списков: `sudo zapret-vn restart`.

## Чем отличается от Windows-версии

| | Windows | Linux |
|---|---|---|
| Интерфейс | значок в трее, окно | командная строка |
| Перехват пакетов | WinDivert | NFQUEUE (nftables / iptables) |
| Защищённый DNS | DoH | **DNS-over-TLS** (systemd-resolved не умеет DoH) |
| «Поиск блокировок» по ~70 сайтам | есть | нет — свои сайты добавляйте в `vietnam.txt` |
| Автоподбор стратегии, автосписок, 10 стратегий | есть | есть |

## Заметки

- **IPv6.** Для nftables правила общие (IPv4 + IPv6). Для iptables ставятся и `ip6tables`, если он есть.
- **VPN/прокси.** Пока включён VPN, трафик к заблокированным сайтам идёт через него, и обход не нужен.
- **Docker, роутеры, NAT.** Правила рассчитаны на обычный компьютер (исходящий трафик самого хоста). Для шлюза/роутера используйте штатные скрипты zapret.
- **Если DNS возвращает `127.0.0.1`** для заблокированных сайтов (так делают вьетнамские провайдеры) — без `dns-on` обход не поможет: сайт просто не найдётся.
- **Удаление:** `sudo zapret-vn uninstall-service && sudo zapret-vn dns-off && sudo rm -rf /opt/zapret-vn /usr/local/bin/zapret-vn`.
